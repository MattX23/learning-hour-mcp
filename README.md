# Learning Hour MCP Server

An MCP (Model Context Protocol) server that helps me to learn from articles and documents by organising content into sections. Then it makes the content accessible to Claude for summarisation and quiz generation.

I needed this to become more efficient during the time I had to learn new topics/skills while at work.
